Pink-noise concepts: Voss/Clarke octave random sources and McCartney's staggered
row updates. References:

- Voss & Clarke, [“1/f noise” in music and speech](https://www.nature.com/articles/258317a0), Nature 258 (1975).
- Original Music-DSP correspondence by James McCartney and Allan Herriman's
  spectral analysis, preserved at [DSP generation of pink noise](https://www.firstpr.com.au/dsp/pink-noise/).
- Marsaglia, [Xorshift RNGs](https://www.jstatsoft.org/article/view/v008i14), Journal of Statistical Software (2003).

This repository implements those mathematical ideas directly. No source code,
filter coefficients, tables, diagrams or explanatory passages were copied from
those publications or the correspondence archive. In particular, it does not
redistribute third-party sample pink-noise implementations or assume a blanket
public-domain license for the archive. The sine table was generated from the
sine formula, and the FFT test was written for this project. This is a provenance
record, not a patent search or legal opinion.

## Brass voice and musical fixture

The brass oscillator tables are original finite Fourier sine sums generated by
`tools/generate_brass_tables.py`, with no recorded samples, SoundFont, borrowed
synthesizer code or third-party waveform tables. Generic voice/sequencer code is
MIT. `src/axel_f_phrase.h` preserves the 23 rounded pitches supplied by
the user for a short Axel F-inspired phrase. Corrected sixteenth-tick onset timing
at117BPM follows the [licensed publisher preview](https://www.notendownload.com/en/axel-f/7060424-pdf);
no score image is redistributed. Gates/release are an articulation approximation.
A [primary composer interview](https://www.redbullmusicacademy.com/lectures/harold-faltermeyer-tokyo-2014/)
notes tempo variation across sections, so this fixed117BPM phrase is not a claim
of exact studio performance microtiming. The supplied metric comments were not treated as an
exact transcription. Musical composition rights are separate from software
licensing. See `LICENSES/Musical-Fixture-Review.txt`: no composition license or clearance is granted.

## Ocean and sawtooth additions

Ocean is an original filtered pink-noise model with deterministic irregular swells,
not a recording. Public ocean tests were moved from an internal mixed-feature test
directory after removing their unrelated runner. The standalone saw mode added
for this package reuses the original finite-Fourier brass saw tables with one
oscillator and a sample-rate-dependent harmonic ceiling. No samples or private
recordings are included.

The optional Pocket C3 board is a separate adaptation of MIT-licensed XiaoZhi
board hardware setup. Its pins and display fallback are independent of the sound
module; installation is explicit.
